통합테스트 세부 기준 ★

참여자 · 등록기준 · 등록유형 · 프로세스 · 결재선 · 위원회 · 결과제출
3-1
필수 참여자
사업부 잡컨설턴트 파트장 / 팀장 포함
3-2
이슈제목 등록기준
[날짜] 이슈유형 (자동생성) - [현장명 필수 입력]
3-3
등록 유형
이슈 등록 필수 기준 · 각 사업부 팀별 노무 / 산업재해 각 이슈 유형 2개 등록

  • 직장내괴롭힘 / 직장내성희롱 유형 중 택 1
  • 기타 진정건 / 복무규정 위반 유형 중 택 1
산업재해 산업재해 테스트 등록 기준
  • 과거 사업부 내 발생 산업재해 Case 2건 등록
3-4
프로세스
노무
이슈등록→ 유형선택→ 기본정보 등록→ 일정 계획→ 결재자 선택→ 단계별 이슈 처리 (상세 내용 입력)→ 내부 결재→ 결과 등록→ 종료
안전
사고 등록→ 기본정보 입력→ 재해 유형 / 정보→ 결재자 선택→ 단계별 사고 처리 (상세 내용 입력)→ 내부 결재→ 결과 등록→ 종료
3-5
결재선 구성
  • 결재자 : 파트장 / 팀장
  • 참조자 : 사업부장
테스트 계정이지만 [사용자 목록] 인원 전부 live 상태입니다. 실제 결재 처리 시 주의해 주세요.
3-6
위원회 구성
  • 위원장 : 팀장 설정
  • 위원 : 팀원 또는 사업부원 설정
판단(심의)위원회 / 징계위원회의 경우, 메일 알림을 통한 참석 여부 확인 및 의결서 동의 여부 확인 액션이 필요합니다.
3-7
테스트 결과 제출
  • 각 사업부 팀별 노무 / 산업재해 각 2건 등록 여부 확인 → 사업혁신실
  • 테스트 완료 후 통합테스트 사이트에서 결과 제출
